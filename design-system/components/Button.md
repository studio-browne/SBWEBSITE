**Button** — the studio's primary action control; uppercase, letter-spaced, near-square corners. Use it for form submits, "View project", "Inquire".

```jsx
<Button variant="primary">Inquire</Button>
<Button variant="clay" size="lg">Book a consultation</Button>
<Button variant="outline" as="a" href="#">View project</Button>
<Button variant="ghost">Read more →</Button>
```

Variants: `primary` (ink fill), `clay` (terracotta accent — use sparingly), `outline` (hairline border), `ghost` (text-only inline). Sizes: `sm`, `md`, `lg`.
