**ProjectCard** — the portfolio unit. A full-bleed interior image with an editorial caption (clay category, serif title, muted location). Hover slowly warms and scales the image.

```jsx
<ProjectCard
  image="assets/images/project-bath.png"
  category="Full-Service Residential"
  title="Cañon Drive Residence"
  location="Beverly Hills, CA"
/>
<ProjectCard image="..." title="Broadway Penthouse" arch ratio="4 / 5" />
```

Set `arch` for the SB arched-top image treatment. Default `ratio` is `3 / 4` (portrait).
