**Eyebrow** — the wide, letter-spaced caps label that precedes headlines and names sections (e.g. "SELECTED WORK", "OUR APPROACH").

```jsx
<Eyebrow rule>Selected Work</Eyebrow>
<Eyebrow tone="clay">Beverly Hills, CA</Eyebrow>
```

Tones: `muted` (default), `clay`, `ink`, `light` (on dark grounds). Set `rule` to prefix a short hairline.
